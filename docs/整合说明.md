# 整合说明：从竞赛交付包到可公开仓库

原始交付包（`挑战杯/`）是参赛时的完整工作目录，共约 **2.5 GB**，夹杂临时脚本、IDE 缓存、中间产物与含敏感凭据的文件。本仓库是在其基础上按「可公开 / 可复现 / 有展示价值」三个标准重新整理的产物，**体积从 2.5 GB 降至 12 MB**。

## 一、纳入仓库的内容

| 原位置 | 仓库位置 | 处理方式 |
| :--- | :--- | :--- |
| `建模分析/code/*.py`（6 个脚本） | `src/` | 路径配置化、输出规范化，算法逻辑未改 |
| `建模分析/*.png`（11 张） | `figures/` | 重命名为英文，并由 `03_visualization.py` 重新生成 |
| `建模分析/数据分析报告完整版_v10.docx` | `docs/reports/` | 原样保留 |
| `多维度数据融合下_修正版.docx` | `docs/reports/项目报告.docx` | 原样保留 |
| `城市公交客流运力调度决策分析平台.pptx` | `docs/reports/答辩演示.pptx` | 原样保留 |
| `smartbi-dashboard-guide/`（HTML + 素材） | `dashboard/` | 入口改名为 `index.html`，可直接静态托管 |
| `天气数据.csv`、`节假日数据.csv` | `data/` | 字段名统一为英文 |
| `建模分析/code/aggregated_data_full.csv`（28 MB） | `data/aggregated_data_full.csv.gz` | gzip 压缩至 2.1 MB，pandas 可直接读 |
| `split_csv.py` | `src/tools/split_large_csv.py` | 重写为流式分块处理（原版全量加载反而更吃内存） |
| `代码说明.md` | `docs/代码说明.md` | 重写，与现行代码一致 |
